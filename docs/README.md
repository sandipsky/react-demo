## How I write these docs

- I write them right after finishing something, while it's still fresh in my head.
- I try to explain the "why", not just the "what". Anyone can copy code — understanding
  why the code is shaped that way is the actual learning.
- If I got confused by something, I write down what confused me and how I figured it out.
